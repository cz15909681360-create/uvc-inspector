# 常见问题

## 找不到检测引擎

2.1.0 的公开下载包已经内置 FFmpeg。确认运行的是新版 EXE；如果内置资源校验失败，请重新下载发行包。缓存位于 `%LOCALAPPDATA%\UvcInspector\engines`，程序会自动修复损坏缓存。使用外部引擎时，点击“选择引擎”指定 `ffmpeg.exe`；该引擎必须可运行且包含 DirectShow。

## 找不到摄像头

确认 Windows 相机隐私设置允许桌面应用访问相机，重新连接设备并点击“刷新设备”。在 Windows 相机应用中先确认设备可用，使用完后关闭它再测试。DirectShow 也可能列出虚拟相机，列表不是 USB/UVC 身份证明。

## 无法打开设备或协商格式失败

关闭会议软件、OBS 与其他使用相机的应用，再选择驱动声明的具体模式。可变尺寸范围不保证范围内所有组合都支持。先尝试较低尺寸和驱动标称帧率；打开“诊断记录”查看实际错误。本软件测试前会停止自身预览，不会关闭其他应用。

## 实际帧率低于请求帧率

界面展示实测值。驱动、光照/曝光、USB 连接、机器性能及 framecrc 校验开销都可能影响结果。仅凭这个数值不能定位硬件掉帧原因，也不能认为设置 60 fps 后设备必然输出 60 fps。

## 码率和 USB 带宽不同

码率按原视频包有效字节与媒体时间计算，不含 USB 协议开销。压缩编码码率随画面变化；RAW 参考值按实际像素存储布局计算。P010 样本为 10-bit，但存储字为 16-bit，不能直接按每样本 10 bit 计算存储量。

## 全屏后画面区域仍然偏矮

点击区域底部“自适应高度”恢复随窗口变化；也可上下拖动手柄。手动高度会保存，下次启动会沿用。画面保持原比例，因此宽高比不匹配时可能出现留边。小窗口可滚动查看下方内容。

## 设置和诊断在哪里

当前用户目录 `%LOCALAPPDATA%\UvcInspector` 下保存 `settings.json` 和意外异常的 `errors.log`。诊断面板包含引擎运行信息。报告和日志可能包含设备标识、用户名或本机路径；提交 Issue 前只保留必要片段，并遮盖这些个人信息。

## 如何重现界面问题

无需连接相机：

```powershell
UvcInspector.exe --demo
UvcInspector.exe --demo --empty --capture ui-empty.png --width 1040 --height 720
UvcInspector.exe --demo --capture ui-large.png --width 2048 --height 1232 --layout-check
```

在 Issue 中提供应用版本、Windows 版本、显示缩放、窗口大小和操作步骤。演示画面只用于布局排错。
